  # День рождения 🎂

Мобильное приложение о датах жизни.<br />
Показывает прожитое время и всю жизнь в неделях, выдаёт достижения за годовщины и серии привычек, помогает примерно спланировать день рождения ребёнка и собирает поздравительную открытку, когда нужные слова не придумываются. В свой день рождения приложение поздравляет само, с конфетти и хлопушками, а о дате близкого человека напоминает за три дня. Дни рождения из контактов собирает в один список и в нужный день подсказывает, кого поздравить.<br />
Всё считается на устройстве, без регистрации и интернета. Рекламы и платных функций нет.

## ✨ Возможности

### 👋 Экскурсия по приложению
- При первом запуске приложение показывает короткие слайды со скриншотами разделов: что оно умеет и где это искать
- Листается свайпом или кнопкой «Далее», экскурсию можно пропустить
- На слайде про контакты функцию можно включить сразу, не заходя в профиль

### 🎂 Важные даты
- Счётчик дней до вашего дня рождения
- Обратный отсчёт до дня рождения близкого человека и срочное напоминание за три дня
- Шпаргалка «кто это»: тёща, начальник и другие, чьё имя лучше не забывать
- Поздравление с конфетти: в день рождения открывается само, в другие дни по кнопке на главной. Им можно поделиться картинкой
- Аватарка-персонаж под настроение и кубик «Решите за меня» для случайного выбора

### 📇 Дни рождения из контактов
- Функция отключаемая: включается тумблером в профиле или прямо на слайде экскурсии, после этого на главной появляется плитка раздела
- Обновившимся пользователям главная предложит функцию сама, но доступ к контактам спросит только по нажатию кнопки
- Все дни рождения из телефонной книги в одном списке, ближайшие наверху. У праздников в ближайшие 60 дней указан день недели. Если в контакте есть год рождения, видно, сколько исполнится
- В день рождения контакта на главной появляется карточка: «Поздравить» открывает открытку с уже вписанным именем, «Уже поздравили» прячет карточку до следующего года
- Контакты читаются только на телефоне: приложение их не сохраняет и никуда не отправляет. Если отозвать доступ в настройках телефона, функция выключится сама

### 🎁 Подарочные открытки
- Генератор поздравлений для другого человека: шесть шаблонов и четыре пула кусочков, это больше 120 тысяч комбинаций
- Имя получателя необязательно: без него у шаблона своя формулировка заголовка, а не обрезанная
- «Ещё вариант» перебирает выдачи и не повторяет последние
- Открытку можно отправить картинкой или скопировать текстом в мессенджер
- Все формулировки безличны: ни рода, ни «ты/вы», поэтому открытка подходит любому получателю

### 🎮 Жизненный прогресс
- Каждая неделя жизни — квадратик, каждая строка — год, всё до расчётного предела
- Живой счётчик прожитого времени: годы, месяцы, недели, дни, часы, минуты, секунды
- Достижения прямо на сетке: возрастные вехи и недели жизни знаменитостей, по тапу открывается подсказка

### 🏆 Достижения
- Семь групп в табах: возраст, знаменитости, борода, диета, спорт, свадьба и особые
- Стрики привычек идут параллельно: у каждого свой запуск, сброс и ручной ввод даты начала, если привычка появилась раньше приложения
- У каждой привычки свой личный рекорд, а после сброса видна и длина прошлой серии
- Достижения за прожитые в браке годы
- Особые достижения не привязаны ко времени: одни находят вас сами, другие прячутся. Во вкладке видны только найденные
- Прогресс-бар до следующего достижения и счётчик пройденных дней внутри группы
- Пять уровней редкости со своей рамкой и иконкой: обычное, редкое, эпичное, легендарное, мифическое
- Карточка достижения открывается модалкой, ей можно поделиться картинкой
- Последнее полученное достижение видно на главной и на странице ачивок
- В `jsons/` лежат заготовки под будущие группы: игры, технологии и дни рождения. К расчёту они пока не подключены

### 👶 Планирование зачатия и рождения
- **Дата зачатия**: по дате рождения покажет примерную дату зачатия и что происходило в тот день
- **Планирование рождения**: выберите желаемый день рождения и получите расчётную дату зачатия
- Праздники, именины, знаки зодиака и памятные даты с учётом диапазона сроков беременности

### ♀️ Планирование для девушек
- Расчёт дня овуляции по дате последних месячных и длине цикла
- Длина цикла запоминается, выбрать её нужно один раз
- Фертильное окно с градацией вероятности зачатия
- Статьи о влиянии алкоголя, курения и других факторов на фертильность

### ♂️ Планирование для мужиков
- Оптимальные дни для зачатия с учётом воздержания от алкоголя и частоты эякуляций
- Алкоголь можно исключить из расчёта одним тапом
- Статьи о том, что влияет на качество спермы

## 🚀 Запуск

### Веб (браузер)

```bash
npm install
npm run dev
```

> В браузере телефонной книги нет, поэтому в dev-режиме раздел контактов и карточки на главной показывают тестовые данные из `api/contactsMock.ts`. В production-сборку они не попадают.

### Android

```bash
npm run build:android
```

> Требуется установленный Android Studio и настроенный Capacitor.

### Сборка APK

```bash
npm run build:apk
```

Собирает debug-версию: `vue-tsc` → `vite build` → `cap sync android` → `assembleDebug`.
Готовый файл — `android/app/build/outputs/apk/debug/app-debug.apk`.

> Нужен `JAVA_HOME` с путём к JDK 21. Подойдёт встроенный в Android Studio,
> на Windows это `C:\Program Files\Android\Android Studio\jbr`.
> Скрипт вызывает `.\gradlew.bat`, то есть рассчитан на Windows.

### Готовые сборки

APK каждой версии лежит в [релизах](https://github.com/k206i/your-birthday/releases).
Их собирает GitHub Actions по пушу тега `v*`, workflow лежит в `.github/workflows/release.yml`.

## ⚙️ Данные и настройки

- **`configApp.ts`** — единая точка настроек: сроки беременности, периоды воздержания, параметры овуляции, продолжительность жизни в неделях, цвета разделов и редкостей достижений.
- **`jsons/achievements_*.json`** — достижения по группам. `age` и `famous` привязаны к неделе жизни через поле `weeks`, стрики (`beard`, `diet`, `sport`) — к числу дней привычки через `days`. Группа определяется префиксом `id`: `beard_7` относится к бороде.
- **`api/getAchievementDate.ts`** — единственное место, где стрик привязан к полю стора. Словарь по типу `TStreakName` не даст добавить новый стрик и забыть про его дату: компилятор потребует запись.
- **`api/syncBirthDateAchievements.ts`** — особые достижения по дате рождения. Правила лежат таблицей, новое добавляется одной строкой. Если дату рождения поменяли и правило больше не выполняется, достижение отзывается.
- **`jsons/gift_card_templates.json` и `gift_card_slots.json`** — шаблоны открыток и пулы кусочков. У шаблона две строки заголовка (с именем и без) и один текст; куски подставляются по имени слота в фигурных скобках. Пул `gift` лежит в родительном падеже и без запятых внутри, `joke` — законченным предложением с заглавной.
- **`jsons/`** — офлайн-датасеты праздников, именин, знаков зодиака, знаменитостей и поздравлений: приложение работает без интернета.
- **`store/contactsStore.ts`** — дни рождения из контактов. Живут только в памяти: на диск не пишутся и никуда не отправляются. Сохраняются лишь флаг включения и отметки «Уже поздравили»: id контакта и дата.
- **`api/getContactsBirthdays.ts`** — чтение контактов. Книга целиком читается при запуске, при включении функции и при входе в раздел. При возврате в приложение проверяется только разрешение, потому что полное чтение дорогое.
