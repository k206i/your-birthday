## ✨ Возможности

- **День зачатия** — введите дату рождения и узнайте примерную дату зачатия, а также какие праздники и именины были в тот день
- **Планирование даты рождения ребёнка** — выберите желаемый день рождения и получите расчётную дату зачатия
- **Праздники и именины** — данные по праздникам с учётом диапазона сроков беременности (преждевременные / нормальные / запоздалые роды)
- **Персонализация** — приветствие по имени пользователя, сохранённому локально

## 🛠 Стек технологий

| Категория       | Технология                              |
|-----------------|-----------------------------------------|
| Фреймворк       | Vue 3 + Composition API (`script setup`) |
| Язык            | TypeScript 5.9 (strict)                 |
| UI / Мобайл     | Ionic 8 + Capacitor 8                   |
| Сборка          | Vite 8                                  |
| Стили           | SCSS + CSS Modules                      |
| Роутинг         | Vue Router 4                            |
| Тесты           | Vitest (unit) + Cypress (e2e)           |
| Хранилище       | Capacitor Preferences                   |

## 🚀 Запуск

### Веб (браузер)

```bash
npm install
npm run dev
```

### Android

```bash
npm run build:andr
```

> Требуется установленный Android Studio и настроенный Capacitor.

## 📁 Структура проекта

```
src/
├── api/              # Получение данных (праздники, именины)
├── assets/           # Шрифты, глобальные стили, изображения
├── components/       # Переиспользуемые компоненты
│   ├── AppFooter/
│   ├── Header/
│   └── Widgets/      # PageTitle, PageLink, DayNamesList, PrimaryDate
├── composables/      # Утилиты Composition API
├── jsons/            # Данные: праздники, именины, зодиак, знаменитости
├── router/           # Маршруты приложения
├── views/            # Страницы
│   ├── HomePage.vue
│   ├── DayConception/
│   └── ChildBirthday/
├── configApp.ts      # Конфигурация (сроки беременности и т.д.)
└── main.ts           # Точка входа
```
